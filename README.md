# BYMAB Studio | Agustina Benavidez

Portfolio de marketing, dirección creativa y producción de contenido. Sitio en inglés, con proyectos de Kline Interiors, El Patio y Eleve.

## Abrir el sitio

Abrir `index.html` en un navegador. HTML y CSS estáticos, sin dependencias, instalación ni compilación.

## Archivos

| Archivo | Función |
| --- | --- |
| `index.html` | Contenido, navegación, proyectos y enlaces |
| `style.css` | Colores, tipografía, espaciado y adaptación a pantallas |
| `favicon.svg` | Icono de la pestaña del navegador |
| `assets/` | Fotografías y material visual |
| `.nojekyll` | Indica que el sitio no requiere procesamiento con Jekyll |
| `.gitignore` | Excluye archivos auxiliares del sistema al usar Git |

## Publicar

Con los archivos en la raíz de `main`, configurar GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save. La guía completa acompaña la carpeta de entrega.

## Personalización

Editar textos y enlaces en `index.html`; estilos en `style.css`. Mantener las rutas relativas de las imágenes para que funcionen también bajo la dirección de un repositorio de GitHub Pages.
